# 시험 기록 형식

기록 한 건은 동일한 장비 구성에서 수행한 비교 시험이다. 환경이 달라지면 별도 기록으로 나눈다.

| 필드 | 용도 |
|---|---|
| title, environment | 보고서 제목과 실제 제품·버전·정책 조건 |
| evidenceSource | 관찰의 출처. 원본을 직접 확인했는지 또는 시험자 요약을 받았는지 기재 |
| document | 공식 문서의 title, url, scope. 생략 가능 |
| rows | 시험 행 배열. 한 행은 한 번의 관찰이며 재시험도 별도 행 |
| target, protocol | 시험 대상과 실제 프로토콜 세대 |
| packetEvidence | 패킷에서 관찰한 사실. 자료가 없으면 null |
| logSni | 추출된 이름은 문자열, 관측한 빈 값은 빈 문자열, 로그 자료가 없으면 null |
| classification | 실제 분류 문자열. 제공되지 않으면 null |
| connection | 시간 초과, 양방향 트래픽, HTTP 응답 등 관측한 수준을 서술 |

스크립트는 구조와 값의 형식을 검사하고 Markdown 표를 표준 출력으로 보낸다. 추출 판정은 logSni에서만 계산한다. 빈 SNI와 관찰 누락은 다른 결과다. 실행 오류는 표준 오류에 표시하고 종료 코드 1을 반환한다. 의존성은 Node.js 내장 모듈뿐이다.
